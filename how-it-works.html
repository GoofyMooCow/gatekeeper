How it works

Every player who attempts to join gets a record. Their status decides whether they get in.

The join flow

  1. A player tries to connect, from Java or Bedrock.
  2. Gatekeeper finds their record, or creates one. New players normally start with the neutral status.
  3. Gatekeeper checks the status. If it allows joining, the player enters. If not, they see the denial screen for that status.
  4. The attempt is written to the join log.

Changing a status

Changing someone's status takes effect immediately. If the new status doesn't allow joining, a player who is online is disconnected.

/gatekeeper status PlayerName banned "Reason"

If something goes wrong

Gatekeeper fails closed. If an access check hits an error, the player is denied instead of accidentally allowed in. See Security.

What gets recorded

LogContainsCommand
Join logJoin attempts/gatekeeper joinlog
Audit logAdministrative changes/gatekeeper audit

A player's record also holds their platform, join information, name history, and profile fields. View it with /gatekeeper info PlayerName.
