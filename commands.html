Commands

Manage players, statuses, profiles, and logs from the console or in game.

The console can always run these. In game, you need OP level 3 or higher. See Permissions.

Gatekeeper commands

CommandWhat it does
/gatekeeper status <player> <status> [reason]Sets a player's status, with an optional reason.
/gatekeeper add <uuid> <username> [status]Creates a record for a player who hasn't joined yet.
/gatekeeper info <player>Shows status, platform, join information, name history, and profile fields.
/gatekeeper delete <player>Deletes a player's record.
/gatekeeper list [query]Lists players, optionally filtered by a search query.
/gatekeeper set <player> <field> <value>Sets a profile field.
/gatekeeper clear <player> <field>Clears a profile field.
/gatekeeper fields listLists the available profile fields.
/gatekeeper statusesLists the available statuses.
/gatekeeper audit [player] [limit]Shows the audit log of administrative changes.
/gatekeeper joinlog [player] [limit]Shows the log of join attempts.
/gatekeeper reloadApplies configuration changes without a restart.

Setting a status

/gatekeeper status PlayerName whitelisted
/gatekeeper status PlayerName neutral
/gatekeeper status PlayerName banned "Reason"

See Player statuses for what each one does.

Vanilla command replacements

Gatekeeper also replaces these common commands. They change Gatekeeper statuses instead of Minecraft's vanilla whitelist.

/whitelist add <player>
/whitelist remove <player>
/whitelist list

/ban <player> [reason]
/pardon <player>

Player information

/gatekeeper info PlayerName

Use this to check a player's status, platform, join information, name history, and profile fields in one place.
