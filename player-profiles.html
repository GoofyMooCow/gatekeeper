Player profiles

Attach information to each player, and decide who gets to see it.

What you can store

Gatekeeper can store custom player information such as Discord username, email, phone, bio, applications, notes, or any other field you define.

Public and private fields

Every field is either public or private.

VisibilityWho can read it
PublicAvailable through the public API, so you can show it on a website.
PrivateOnly available through the authenticated admin API.

Private fields are always left out of public API responses.

Working with fields

/gatekeeper fields list
/gatekeeper set GoofyMooCow discord goofymoocow
/gatekeeper clear GoofyMooCow discord
/gatekeeper info GoofyMooCow

Fields are defined in config/gatekeeper/fields.json. Run /gatekeeper reload after changing it.

Treat private fields like private data: emails and phone numbers should only ever be reachable with your admin token. See Security.
