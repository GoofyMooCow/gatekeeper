Gatekeeper

A server-side Fabric mod that gives you complete control over who can access your Minecraft server.

Install Gatekeeper Screen Configurator

Unlike Minecraft's basic whitelist, Gatekeeper introduces flexible player statuses, custom denial screens, player profiles, detailed audit logging, and a powerful HTTP API for external integrations. It supports both Java Edition and Bedrock Edition players when used with Geyser/Floodgate.

Why Gatekeeper?

Gatekeeper is a modern replacement for Minecraft's whitelist system. Instead of managing a simple list of allowed and denied players, you can build a complete onboarding and access-management workflow with custom statuses, profile fields, denial messages, and external integrations.

Whether you're running a private server, a community server with applications, or a large network with custom tooling, Gatekeeper lets you manage player access your way.

Features

Flexible player statuses
Built-in whitelisted, neutral, and banned, plus your own custom statuses.
Custom denial screens
Fully customizable messages for players who are denied access.
Java & Bedrock support
Seamless compatibility with Geyser/Floodgate.
Player profiles
Store Discord usernames, email addresses, bios, applications, notes, and more.
Public and private fields
Choose what is visible publicly and what stays admin-only.
Join and audit logging
Record login attempts and administrative actions for moderation and accountability.
HTTP API
Integrate with websites, Discord bots, dashboards, and custom applications.
In-game administration
Manage players, statuses, and profiles directly from Minecraft.
Hot-reload configuration
Apply most changes instantly with /gatekeeper reload.
Fail-closed security
If an access check fails unexpectedly, players are denied rather than mistakenly let in.
