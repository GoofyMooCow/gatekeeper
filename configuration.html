Configuration

Gatekeeper keeps its settings in three files, and most changes apply without a restart.

Files

config/gatekeeper/
├── config.json
├── messages.json
└── fields.json
FileUsed for
config.jsonGeneral settings, including the HTTP API and its admin token.
messages.jsonDenial screens. The Screen Configurator generates this for you.
fields.jsonPlayer profile fields and their visibility.

Reloading

Apply most changes with:

/gatekeeper reload

No restart is required.
